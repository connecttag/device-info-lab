# Device Info Lab — مريم لينك

مشروع مستقل مبني بـ **Cloudflare Workers + D1 + Static Assets**، بلوحة تحكم عربية تدعم RTL. اسم المجلد والـWorker هو `device-info-lab`، وقاعدة البيانات `device-info-lab-db`؛ **مريم لينك** هو اسم الواجهة فقط.

- روابط الزيارة: **https://info.aslyemen.com**
- الإدارة: **https://devics-panel.aslyemen.com** (هذه هي التهجئة المعتمدة)
- المستودع: https://github.com/connecttag/device-info-lab

## ما الذي يقدمه؟

- إنشاء روابط عشوائية طويلة، بصلاحية من يوم إلى 90 يومًا، ونسخها وتعطيلها وحذفها مع بياناتها.
- تسجيل معلومات الطلب تلقائيًا في D1 عند فتح رابط صالح، دون زر موافقة.
- استكمال معلومات المتصفح بـJavaScript في **سجل الزيارة نفسه** باستخدام تفويض موقّع لعشر دقائق، صالح لتحديث واحد.
- ستة قوالب: ترحيب، معلومات الجهاز الحالي، صفحة ترويجية، صفحة HTTP 404 فعلية، نموذج دخول تدريبي، ونص مخصص.
- تخصيص العنوان والرسالة واسم الشركة ورابط موقعها HTTPS. المحتوى نص عادي؛ لا يقبل HTML أو JavaScript.
- لوحة مسؤول محمية، وإحصاءات وبحث وتصفية وترقيم صفحات وتفاصيل وتصدير JSON حتى 250 سجلًا مطابقًا.
- لا توجد لوحة حساب للزائر. قالب معلومات الجهاز يعرض معلومات زيارته الحالية فقط. بقية النتائج تظهر للمسؤول.
- خط Tajawal عربي محلي مرخص بـSIL OFL، ورموز تعبيرية للتنقل والإحصاءات والأزرار وحالات الفراغ، دون تحميل خط أو مكتبة أيقونات من خدمة خارجية.

## بيانات الزيارة

**الحافة والطلب:** IP العام وإصداره، User-Agent، المتصفح والنظام وإصداراتهما المستنتجة، نوع الجهاز المستنتج، اللغات، الدولة/المدينة/المنطقة والإحداثيات التقريبية بحسب IP، ASN والمشغل، HTTP وTLS وخوارزميته ومركز Cloudflare وأزمنة الاتصال عند توفرها.

**المتصفح:** الشاشة والمساحة المتاحة ونافذة الصفحة وكثافة البكسل والألوان والاتجاه، اللغة واللغات والتوقيت، اللمس، مؤشرات المعالج والذاكرة التي يتيحها المتصفح، الاتصال وسرعته التقديرية وتوفير البيانات، Client Hints المتاحة عادةً، ونمط الألوان.

**الترويسات:** قائمة إيجابية للترويسات الاعتيادية المرتبطة بالمتصفح والشبكة وClient Hints. لا تُحفظ Cookie أو Authorization أو الترويسات المخصصة غير المعروفة التي قد تحمل أسرارًا. تُختزل Referer إلى اسم المصدر، وتُستبعد المسارات والمعاملات.

هذه معلومات تشخيصية يتيحها الويب، وليست كشفًا كاملًا لمكونات الجهاز أو إثباتًا لهوية مستخدمه. بعض الحقول غير متاحة أو تقريبية أو يمكن تعديلها؛ وقد يعكس IP شبكة VPN أو وسيطًا. لا توجد قراءة لملفات الجهاز أو الكاميرا أو الميكروفون أو GPS أو IMEI أو MAC أو كلمات مرور حقيقية، ولا بصمة Canvas/WebGL أو تتبع عبر المواقع.

## نموذج الدخول التدريبي

خدمة خيالية تستخدم بيانات **عامة ومحددة للمختبر**:

```text
student.demo
Demo-Only-2026!
```

يتحقق المتصفح والخادم من هاتين القيمتين فقط. تُحفظ قيم التدريب في سجل الزيارة للمراجعة اللاحقة داخل لوحة الإدارة. لا يُحفظ أي حساب حقيقي أو كلمة مرور يختارها الزائر. الحقول معطّلة في HTML حتى تثبيت التحقق بـJavaScript، والنموذج لا يرسل بيانات في عنوان URL.

## التشغيل المحلي

المتطلبات: Node.js 22.9 أو أحدث، وnpm. اختبارات SQLite تستخدم الميزة التجريبية المدمجة في Node؛ يوصى بإصدار Node LTS حديث.

```powershell
npm ci
Copy-Item .dev.vars.example .dev.vars
```

اضبط قيمتين عشوائيتين مختلفتين بطول 32 حرفًا أو أكثر في `.dev.vars`، وأبقِ `APP_ENV="development"` محليًا. لا تضع المفاتيح في المستودع أو عنوان الرابط أو كود الواجهة.

```powershell
npm run d1:migrate:local
npm run dev
```

افتح **http://127.0.0.1:8787**. وضع التطوير يوحّد واجهتي الزيارة والإدارة على loopback لتسهيل الفحص. السكربت يضبط `--host 127.0.0.1` لأن مسارات النطاقات في Wrangler قد تعيد كتابة عنوان الطلب عند ترك القيمة الافتراضية.

## Cloudflare والنشر

ملف `wrangler.jsonc` يحتوي معرّف حساب وقاعدة D1 المخصصة لهذا المشروع، وهما معرفان عامان وليسا أسرارًا. لا يرتبط المشروع بقاعدة `soor-db` أو كود `soor-api`.

لنسخة مستقلة بحساب آخر، أنشئ قاعدة جديدة وعدّل `account_id` و`database_id` والنطاقات والمتغيرات:

```powershell
npx wrangler login
npm run d1:create
```

للنشر على القاعدة المهيّأة، نفّذ الترحيل وضع الأسرار ثم انشر:

```powershell
npm test
npm run check
npm run d1:migrate:remote
npx wrangler secret put ADMIN_KEY
npx wrangler secret put TOKEN_SECRET
npm run deploy
```

استخدم إدخال Wrangler التفاعلي للأسرار، أو `wrangler secret bulk` مع ملف أسرار محلي خارج المستودع. لا تمرّر قيم الأسرار كوسائط أمر. لا تُضاف `.dev.vars` للنشر؛ بيئة الإنتاج تستخدم `APP_ENV=production` من الإعدادات.

## الحماية والاحتفاظ

- نطاق الإدارة وحده يخدم API الإدارة وملفاتها؛ لا يتاح ذلك عبر نطاق الزيارة أو workers.dev.
- جلسة مسؤول 8 ساعات في Cookie مرتبطة بالمضيف، HttpOnly وSameSite=Strict وSecure عبر HTTPS. لا توجد كلمة مرور افتراضية في المصدر.
- رموز الجلسات محفوظة بتجزئة مرتبطة بمفتاح الإدارة؛ تدوير المفتاح يبطل الجلسات القائمة.
- الكتابات تتطلب Origin مطابقًا للمضيف؛ لا يوجد CORS مفتوح.
- استعلامات D1 مربوطة، وCSP، وعرض النصوص بـtextContent/escaping، وحدود لأحجام الطلبات والتصدير.
- حد تسجيل دخول 10 محاولات/15 دقيقة لكل IP، وحد زيارة 120 طلبًا/دقيقة لكل IP، وحماية إرسال التدريب؛ العدّادات في D1.
- الاحتفاظ بالزيارات 30 يومًا. تتوقف قراءتها فور انتهاء المدة، وتحذفها مهمة يومية الساعة 03:17 UTC مع الجلسات والعدادات المنتهية.
- لا تُكتب أسرار أو بيانات زيارات في console، وسجلات الاستدعاءات الآلية معطلة. سياسات سجلات Cloudflare على مستوى الحساب مستقلة عن التطبيق.

معاينات Telegram وWhatsApp والـprefetch المعروفة مستبعدة من التسجيل. وصول طلب لا يثبت أن المستلم نقر الرابط، وتصنيف User-Agent ليس ضمانًا لاكتشاف كل الروبوتات. JavaScript قد يُحظر؛ عندها يبقى سجل الحافة دون تفاصيل المتصفح.

## بنية المصدر والتحقق

```text
src/controllers/     HTTP validation and responses
src/services/        Visit, auth, link and training behavior
src/repositories/    Prepared D1 queries
src/utils/           Crypto, metadata, origins, validation
src/views/           Escaped public page templates
public/              Arabic dashboard and visitor assets
migrations/          Independent D1 schema
tests/               Security, routes, templates and real SQLite tests
```

```powershell
npm test
npm run check
npx wrangler deploy --dry-run
```

تفاصيل الـREST API في [docs/API.md](docs/API.md). القيم التجريبية وأسماء المؤسسات في الاختبارات ليست بيانات مستخدمين أو أسرار إنتاج.

للتحقق الشامل من نسخة منشورة، اضبط `DEVICE_LAB_ADMIN_KEY` في بيئة العملية ثم نفّذ `npm run smoke`. السكربت ينشئ روابط فحص مؤقتة للقوالب الستة ويحذفها مع سجلاتها عند الانتهاء؛ لا تطبّقه على رابط يخص مستخدمًا آخر.

التحقق المنفّذ في 2026-10-24: نجح 18 اختبارًا محليًا و80 تحققًا سحابيًا، مع فحص الواجهة على Chrome وIAB بعرض الهاتف 390px وسطح المكتب 1536px. لم يُنفّذ اختبار على جهاز هاتف فعلي أو داخل متصفح WhatsApp/Telegram.
