# Preview, analytics and link tools

User-selected scope: desktop/mobile preview before creation, promotional title/logo/colors, date and template/browser/OS/country distributions and training counts, QR, duplicate, hours expiry, usage cap, groups.

Additional user steering: editable site brand in dashboard settings. Default is مريم لينك, 1..80 trimmed characters. D1 singleton is authoritative; public branding endpoint exposes only this display name, admin same-origin authenticated PATCH changes it. Apply to dashboard/login/browser titles, preview and visitor/landing/unavailable pages. Folder/database/domains do not change.

Keep existing Arabic design system, authentication, host isolation, fictional fixed-demo training and retention. No third-party tracking/QR/image services. No real credentials. Preview shares the visitor renderer but omits scripts and capabilities, records nothing, and is sandboxed. Logo is an optional embedded raster (PNG/JPEG/WebP), max 24 KiB; colors are validated six-digit hex values. Preview viewport is 390 or 1280 CSS pixels, scaled to fit.

Canonical duration is integer expiresInHours, 1..2160; existing expiresInDays API remains accepted if hours absent. Usage cap is optional 1..1000000, counting admitted human GET records for the link lifetime, independently of retention. Atomic conditional insert plus SQLite trigger increments useCount; HEAD/prefetch/known bots do not count. Enrichment/training for the final admitted visit remains possible. Duplicate opens a prefilled creation form with new token, fresh expiry, zero usage and no copied visits. Existing links remain unlimited.

Groups have unique case-insensitive names (1..80), at most 100; create, rename, delete and assign/move links. Deleting a group unassigns links without deleting them. Filters share one predicate across stats, visits and export: inclusive UTC calendar from/to, group, link, template, browser, OS, country and query. Totals respect the selected filters; totalLinks remains global. Distributions include every category with unknown bucket. Retained records only; form submission means one successful saved demo form per visit.

QR is generated by the Worker from the stored URL using pinned local library, available only to authenticated admins, downloadable SVG. Add an additive D1 migration, retain all existing records.
